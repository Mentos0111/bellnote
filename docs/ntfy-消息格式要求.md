# 给 ntfy 发送脚本的格式要求（Bellnote 识别标准）

> 用途：把这个工作区（或任意发 ntfy 的脚本）以后的推送内容，统一改成下面的格式。
> 直接复制「发给对方的话」整段过去即可。

---

## 发给对方的话（可整段复制）

我手机装了 **Bellnote**，它监听 `io.heckel.ntfy` 的通知并自动解析写进系统日历。以后这个脚本发的每条 ntfy 消息，请严格按下面的格式来。

**一、一条通知 = 一条待办。** 多条待办请分多条发，不要塞进同一条消息。

**二、正文（body）用中文键值，每行一条：**

```
标题：数学作业
时间：2026-11-08 19:00
时长：90
备注：第三章习题
重复：weekly
```

这样通知列表里显示的是正常中文。**也可以用一行 JSON**（效果一样，只是通知里会看到花括号）：

```json
{"title":"数学作业","time":"2026-11-08 19:00","duration":90,"note":"第三章习题","repeat":"weekly"}
```

字段规则：

- **标题** / `title`：必填，≤30 字；不要加 emoji 前缀、序号、书名号，直接写内容（会原样变成日历事件标题）
- **时间** / `time`：**必填**，格式严格为 `yyyy-MM-dd HH:mm`（24 小时制、北京时间 Asia/Shanghai）；不要带时区后缀、不要用 `T` 分隔、不要只写「19:00」或「明天」
- **时长** / `duration`：整数分钟，5–1440，缺省 60
- **备注** / `note`：可省略。**键值格式下只能写一行**（换行会被压成 ` · `），需要多行就改用 JSON 的 `\n`
- **重复** / `repeat`：只能是 `none` / `daily` / `weekly` / `monthly` / `yearly`，缺省 `none`；键值格式里中文（每周 / 每天）也认
- 不要塞 `id` / `type` / `topic` 之类自定义字段，用不上

**三、通知标题（ntfy 的 `title`）也请写成这条待办本身的标题**（如「化学课」），不要固定写成「待办日历」——这样通知列表一眼能看出是什么事，而正文里的「标题：」仍然是 App 的判断依据。

**四、不要发这些形式：** 纯口语一句话、Markdown 表格、把时间写成 `19:00`（只给时间没日期会被当成今天/明天，容易错）。

**五、发之前自检三条：**
1. 正文里能读出「标题」和「时间」；
2. `time` 是未来时间；
3. `repeat` 在允许值列表里。

**六、同一内容 60 秒内不要重复发**，App 会自动去重，重复发等于白发。

> **重要：App 2.4 起是严格模式**——正文里必须能解析出「时间」才会写进日历。解析不出来的消息（纯聊天、脚本状态、测试文案）会被**直接忽略**，不会再像以前那样按「收到时间 +1 小时」塞进日历。

## 备注（自己看，不用发出去）

- App 只监听官方 ntfy 安卓客户端（包名 `io.heckel.ntfy`）的通知；脚本往哪个 topic 发，手机 ntfy 必须订阅同一个 topic 且通知没被系统关掉，否则 App 什么都收不到。
- 解析入口：`app/src/main/java/com/bellnote/parser/TodoParser.kt`；格式若调整，同步改这里和 `app/src/test/java/com/bellnote/parser/TodoParserTest.kt`（那里有用本脚本真实输出做的对接测试）。
- 一条 ntfy 通知只解析一条待办（同名键取第一处）。截图识别才支持一次出多条。

## 删除待办

发一条 ntfy 即可远程删除日历待办，两种写法：

```
删除：数学作业
删除：数学作业 2026-11-08 19:00
```

```json
{"action":"delete","title":"数学作业","time":"2026-11-08 19:00"}
```

规则：

- 只删 App 自己写入的事件（带 `[bellnote]` 标记），别的 App 建的日程不会动
- 标题必须**完全一致**（全角/半角空格、多余空白的差异会被忽略）；带日期时按同一天再收窄
- 匹配到几条删几条，结果会回一条通知：「已删除 N 条待办」
- 一条都没匹配到就只回「没找到要删的待办」，不做任何改动
- 同名待办多又想只删一条，务必带上日期时间
