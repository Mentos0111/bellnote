# 给 ntfy 发送脚本的格式要求（ntfy 待办日历 App 识别标准）

> 用途：把这个工作区（或任意发 ntfy 的脚本）以后的推送内容，统一改成下面的格式。
> 直接复制「发给对方的话」整段过去即可。

---

## 发给对方的话（可整段复制）

我手机装了「ntfy 待办日历」App，它监听 `io.heckel.ntfy` 的通知并自动解析写进系统日历。以后这个脚本发的每条 ntfy 消息，请严格按下面的格式来，否则会被当成「认不出」，只能落成兜底待办（时间=收到时间+1小时、时长60分钟）。

**一、一条通知 = 一条待办。** 多条待办请分多条发，不要塞进同一条消息。

**二、正文（body）用一行 JSON，不要 markdown 代码块，前后不要加任何说明文字：**

```json
{"title":"数学作业","time":"2026-11-08 19:00","duration":90,"note":"第三章习题","repeat":"weekly"}
```

字段规则：

- `title`：必填，字符串，≤30 字；不要加 emoji 前缀、序号、书名号，直接写内容（会原样变成日历事件标题）
- `time`：必填，格式严格为 `yyyy-MM-dd HH:mm`（24 小时制、北京时间 Asia/Shanghai）；不要带时区后缀、不要用 `T` 分隔、不要写「明天 / 后天 / 19:00 只有时间」
- `duration`：整数分钟，5–1440，缺省 60
- `note`：可省略；多行用 `\n` 转义
- `repeat`：只能是 `none` / `daily` / `weekly` / `monthly` / `yearly`，缺省 `none`
- 不要塞 `id` / `type` / `topic` 之类自定义字段，用不上

**三、通知标题（ntfy 的 title/`-t`）随便写**（如「作业提醒」），App 以 body 里的 `title` 为准。

**四、不要发这些形式：** 纯口语一句话、Markdown 表格、多行键值文本和 JSON 混写、把时间写成 `19:00`（只给时间没日期会被当成今天/明天，容易错）。

**五、发之前自检三条：**
1. body 能被 `JSON.parse` 解析；
2. `time` 是未来时间；
3. `repeat` 在允许值列表里。

**六、同一内容 60 秒内不要重复发**，App 会自动去重，重复发等于白发。

如果脚本不方便输出 JSON，可以退而用下面这种键值文本（每行一条，中英文冒号都认）：

```
标题：数学作业
时间：2026-11-08 19:00
时长：90
备注：第三章习题
重复：每周
```

## 备注（自己看，不用发出去）

- App 只监听官方 ntfy 安卓客户端（包名 `io.heckel.ntfy`）的通知；脚本往哪个 topic 发，手机 ntfy 必须订阅同一个 topic 且通知没被系统关掉，否则 App 什么都收不到。
- 解析入口：`app/src/main/java/com/ntfycalendar/parser/TodoParser.kt`；格式若调整，同步改这里和 `app/src/test/java/com/ntfycalendar/parser/TodoParserTest.kt`。
- 目前一条通知只解析一条待办（同名键取第一处，后续行会并入备注）。

## 删除待办（v2.1 起支持）

发一条 ntfy 即可远程删除日历待办，两种写法：

```json
{"action":"delete","title":"数学作业"}
```

```
删除：数学作业
删除：数学作业 2026-11-08 19:00
```

规则：

- 只删 App 自己写入的事件（带 `[bellnote]` 标记），别的 App 建的日程不会动
- 标题必须**完全一致**；带日期时按同一天再收窄，用来区分同名待办
- 匹配到几条删几条，结果会回一条通知：「已删除 N 条待办」
- 一条都没匹配到就只回「没找到要删的待办」，不做任何改动
- 同名待办多又想只删一条，务必带上日期时间
